    API reference¶

    Generated from the docstrings in liveplot/liveplot.py. One public class, LivePlot; panels and axes are handles you get from it:

    Object Get it with

    Panel plot.panels[i], plot[metric].panel, LivePlot.subplots

    LivePlot¶

    LivePlot ¶

    LivePlot(
    *args,
    total: int | None = None,
    initial: int | float = 0,
    unit: str = "step",
    unit_scale: int | float = 1,
    refresh_seconds: float = 1.0,
    max_cols: int | None = 3,
    rows: int | None = None,
    cols: int | None = None,
    cell_size: tuple = (5, 3.5),
    dpi: int = 100,
    show: bool = True,
    progress: bool = True,
    desc: str | None = None,
    record: bool | str = False,
    smooth: float | None = None,
    fixed_x: bool = False,
    si_xticks: bool = False,
)

    A live plot of the metrics you log, with a tqdm progress bar underneath.

    Metrics are named when you log them: plot.log(loss=0.3). Each name becomes a curve, and the figure redraws in the notebook's output cell while the loop runs.

    The x value of a point is the plot's step counter at the time of the log call. log itself does not advance the counter. Advance it in one of three ways:

    1. Iterate the plot: for batch in LivePlot(loader). Each item advances the counter by one.
    2. Wrap an inner loop with plot(loader), or call plot.update() once per step. Use these for nested epoch and batch loops.
    3. Pass the x value yourself: plot.log(step, loss=0.3).

    If you do none of these, every point is logged at the same x (initial, 0 by default) and the curve collapses to a vertical line.

    Outside a notebook nothing is drawn, but data still collects everything.

    Example 
    from liveplot import LivePlot

plot = LivePlot(loader, "loss | acc", "lr")   # two panels; acc on a right-hand axis
plot["acc"].set_ylim(0, 1)
for batch in plot:                            # wrapping the loader advances x
    loss, acc = train_step(batch)
    plot.log(loss=loss, acc=acc, lr=get_lr())

    Create a plot: LivePlot([iterable,] *panels, **options).

    Parameters:

    Name Type Description Default
    *args Any

    An optional iterable, then any number of panel layouts.

    The iterable is anything you would loop over: a range, a DataLoader, an existing tqdm bar. If the first argument is not a string or a dict, it is taken as the iterable. Iterating the plot then yields its items, advances x by one per item, shows a progress bar, and calls finish() when the loop ends. An existing tqdm bar is reused, not wrapped in a second one. Leave the iterable out for nested loops and use plot(inner_iterable) or plot.update().

    Each layout string is one panel. Names separated by spaces share the left y-axis. Names after a | go on a right-hand y-axis: "loss", "train_loss val_loss", "loss | acc". With no layout, every metric you log shares one panel. With a layout, a metric that no string mentions gets a panel of its own. A dict such as {"metrics": ["acc"], "ylim": (0, 1)} is also accepted in place of a string, but the setters are the intended way to configure a panel.

    		 ()
    total int | None

    Number of items in the whole run. Optional. Defaults to len(iterable) when there is an iterable with a length. It does two things. It is the length of the progress bar when the bar cannot get one from the iterable: the bar that update() opens, and the bar for an iterable that has no len(). And with fixed_x=True it fixes the x range. With the default fixed_x=False it does not change the figure. Bars made by plot(iterable) use len(iterable).

    		 None
    initial int | float

    The x value of the first item. Use initial=1 for a 1-based x-axis.

    		 0
    unit str

    Name of one item. It is the default x label and the unit on the progress bar.

    		 'step'
    unit_scale int | float

    How much x advances per item. x = initial + n * unit_scale. For example unit="examples", unit_scale=batch_size plots against examples seen.

    		 1
    refresh_seconds float

    Minimum time between redraws. Points that arrive in between are drawn together in the next frame. 0 redraws whenever new data arrives.

    		 1.0
    max_cols int | None

    Widest grid of panels. None gives a near-square grid.

    		 3
    rows int | None

    Fix the number of grid rows.

    		 None
    cols int | None

    Fix the number of grid columns.

    		 None
    cell_size tuple

    (width, height) of one panel, in inches.

    		 (5, 3.5)
    dpi int

    Resolution of the rendered image.

    		 100
    show bool

    False draws nothing. Metrics are still collected in data and shown on the progress bar.

    		 True
    progress bool

    False shows no progress bar.

    		 True
    desc str | None

    Text before the progress bar, for the bar made by iterating the plot or by update(). Bars made by plot(iterable, desc=...) take their own.

    		 None
    record bool | str

    True keeps every rendered frame in frames. A path such as "run.gif" also writes an animated GIF there at finish(). Recording works outside a notebook too.

    		 False
    smooth float | None

    Default smoothing weight for every panel, from 0 up to but not including 1. See set_smooth.

    		 None
    fixed_x bool

    False (the default) lets the x-axis grow with the data. True, with a known total, fixes the x-axis to (initial, initial + total * unit_scale) from the first frame, so the curve grows into an axis that already spans the run. It has no effect without a total.

    		 False
    si_xticks bool

    True labels the x-axis with SI prefixes (100k, 1.5M, 2G, 3T), for long runs whose tick labels would otherwise run into each other, e.g. 300000 examples. Axes below 10,000 are unchanged, and from 1e15 matplotlib's scientific notation is used. False (the default) leaves matplotlib's usual labels.

    		 False

    panels property ¶

    panels: list

    The panels of the grid, in order, as a list of Panel.

    Example 
    plot.panels[0].set_title("training")

    x_range property ¶

    x_range

    The fixed x-axis range, or None when the x-axis follows the data.

    It is (initial, initial + total * unit_scale) when fixed_x=True and total is known, and None otherwise.

    step property ¶

    step

    The x value that a log() call without an explicit step gets right now.

    Once a loop is wrapped or update() has been called, this is initial + n * unit_scale. Before that, it is the step of the last log(step, ...) call, or initial if there has been none.

    subplots classmethod ¶

    subplots(
    nrows: int = 1,
    ncols: int = 1,
    *,
    figsize=None,
    squeeze: bool = True,
    width_ratios=None,
    height_ratios=None,
    iterable=None,
    **kwargs,
)

    Create a plot with a fixed grid of empty panels, like plt.subplots.

    Fill each panel with ax.plot("loss", ...) for curves or ax.imshow(tensor) for an image. The grid never grows: a metric you log without placing it joins the first panel that is still empty, or the first curve panel if none is empty.

    Parameters:

    Name Type Description Default
    nrows int

    Number of grid rows.

    		 1
    ncols int

    Number of grid columns.

    		 1
    figsize tuple[float, float] | None

    (width, height) of the whole figure in inches. Without it, each panel is cell_size inches.

    		 None
    squeeze bool

    True returns one Panel for a 1x1 grid, a flat list for a single row or column, and a 2-d grid otherwise. False always returns the 2-d grid.

    		 True
    width_ratios Sequence[float] | None

    Relative column widths, one per column, e.g. (1, 1.3).

    		 None
    height_ratios Sequence[float] | None

    Relative row heights, one per row.

    		 None
    iterable Iterable | None

    An iterable to wrap, as in LivePlot(iterable).

    		 None
    **kwargs Any

    Any other LivePlot option, such as total or smooth.

    		 {}

    Returns:

    Type Description
    tuple[LivePlot, Panel | list[Panel] | _PanelGrid]

    (plot, axes), the plot and its panels.
    Example 
    plot, (ax_loss, ax_samples) = LivePlot.subplots(1, 2, figsize=(11, 4))
ax_loss.plot("lossD", "lossG")           # two metrics on the left axis
ax_loss.twinx().plot("D_real")           # one on the right-hand axis
for batch in plot(loader):
    plot.log(lossD=..., lossG=..., D_real=...)
    if plot.n % 250 == 0:
        ax_samples.imshow(netG(fixed_noise), rows=2, vmin=-1, vmax=1)
plot.finish()

    __call__ ¶

    __call__(iterable, **tqdm_kwargs)

    Wrap a loop so that each item advances the x-axis by one step: plot(loader).

    Use this for nested loops. Create the plot once, then wrap the inner loop on every epoch. The step count continues from one wrapped loop to the next, and each gets its own progress bar of length len(iterable). The count is 0 inside the body for the first item, like for step in range(n). The plot is not finished when the loop ends, so call finish() yourself or use with.

    Parameters:

    Name Type Description Default
    iterable Iterable

    What to loop over. An existing tqdm bar is reused.

    		 required
    **tqdm_kwargs Any

    Passed to tqdm, e.g. desc="epoch 3".

    		 {}

    Yields:

    Type Description
    Any

    The items of iterable.
    Example 
    plot = LivePlot("loss", "acc")
for epoch in range(epochs):
    for batch in plot(loader, desc=f"epoch {epoch}"):
        plot.log(loss=train_step(batch))     # one point per batch
    plot.log(acc=evaluate())                 # one point per epoch
plot.finish()

    update ¶

    update(n=1)

    Advance the x-axis by hand, like tqdm's update.

    Use this when you do not want to wrap the loop. Call it once per step, after logging that step's metrics. The first call opens one progress bar for the whole run, of length total if you gave one, and finish() closes it.

    Parameters:

    Name Type Description Default
    n int

    How many items to advance by.

    		 1
    Example 
    plot = LivePlot(total=epochs * len(loader))   # total only sets the bar's length
for epoch in range(epochs):
    plot.set_description(f"epoch {epoch}")
    for batch in loader:
        plot.log(loss=train_step(batch))
        plot.update()
plot.finish()

    __iter__ ¶

    __iter__()

    Iterate over the iterable given to the constructor: for batch in plot.

    Each item advances the x-axis by one step, a progress bar is shown, and finish() is called when the loop ends, including when it ends with break or an exception. Raises TypeError if the plot was created without an iterable.

    log ¶

    log(*args, **metrics)

    Record one value for each of one or more metrics.

    A metric is created the first time you log it. Each call adds one point per metric, at the plot's current x (plot.step). Metrics can be logged at different rates: each keeps its own list of points.

    log does not advance x. Wrap the loop (for batch in plot or plot(loader)), call plot.update(), or pass the step as the first argument. Otherwise every point has the same x.

    Parameters:

    Name Type Description Default
    *args Any

    Optionally the x value for this call, then optionally a dict of metrics: log(step, loss=0.3), log(step, {"loss": 0.3}) or log({"loss": 0.3}). In a wrapped loop an explicit step applies to this call only. With no wrapped loop it also becomes the x of later calls that give no step.

    		 ()
    **metrics float

    Metric values by name: log(loss=0.3, acc=0.9). A value is anything float() accepts, including a one-element tensor.

    		 {}
    Example 
    plot = LivePlot(range(1000), "loss | acc")
for step in plot:
    plot.log(loss=train_step())      # every step
    if step % 50 == 0:
        plot.log(acc=evaluate())     # every 50 steps, same x-axis

    figure ¶

    figure()

    Build a matplotlib Figure of the plot as it stands.

    The figure has the same panels, data, reference lines and images as the live plot. It is built from data on the calling thread and is separate from the live display, so changing it does not change the live plot. It works during or after the run, and also with show=False or outside a notebook.

    Returns:

    Type Description
    Figure

    A new figure.
    Example 
    fig = plot.figure()
fig.suptitle("run 12")
fig.savefig("run12.png", dpi=150)

    refresh ¶

    refresh()

    Redraw now, if drawing happens on the calling thread (mode == "thread").

    In the usual mode a separate process draws on its own schedule and this does nothing.

    finish ¶

    finish()

    Draw the final frame, close the progress bar and stop the render process.

    Iterating the plot (for batch in plot) and the with block call this for you. Call it yourself after nested loops that use plot(loader) or plot.update(). Calling it twice is safe. data stays available afterwards. If record was a path, the GIF is written here.

    __enter__ ¶

    __enter__()

    Use the plot as a context manager: finish() is called when the block exits.

    Example 
    with LivePlot("loss") as plot:
    for step in range(num_steps):
        plot.log(step, loss=train_step())

    Panel¶

    Panel ¶

    Panel(plot, index: int)

    One panel of the grid: a set of curves with one or two y-axes, or one image.

    You do not create these. Get one from plot.panels[i], from plot[metric].panel, or from LivePlot.subplots, which returns the panels of a fixed grid.

    A panel has a title, an x-axis, a legend and a smoothing weight, and up to two y-axes: panel.left and panel.right. The y setters on the panel itself (set_ylabel, set_ylim, set_yscale, axhline) act on the left axis.

    Setters can be called before the loop or during it. The figure is laid out again on the next frame.

    Example 
    plot = LivePlot(loader, "loss | acc", "lr")
plot.panels[0].set_title("training")
plot.panels[0].right.set_ylim(0, 1)   # the axis holding acc
plot.panels[1].set_yscale("log")      # the lr panel

    spec property ¶

    spec: dict

    The panel's settings as a dict (title, metrics, limits, ...). Mostly for debugging.

    metrics property ¶

    metrics: list

    Names of the metrics on this panel: the left axis's first, then the right axis's.

    left property ¶

    left: _Axis

    The left y-axis.

    right property ¶

    imshow ¶

    imshow(
    x,
    *,
    rows=None,
    cols=None,
    griddim=None,
    vmin=None,
    vmax=None,
    scale_each=False,
    channels=None,
    cmap="gray",
    padding=0,
    pad_value=0,
    max_images=64,
    max_cols=8,
)

    Show an image, or a batch of images as a grid, on this panel.

    Each call replaces the previous picture. Once the plot has a step (a loop is wrapped or something has been logged), the panel's title shows the step the picture was drawn at.

    Accepted shapes: (H, W), (1, H, W), (H, W, 3|4), (B, H, W), (B, 1|3|4, H, W) and (B, H, W, 1|3|4). (3, H, W) and (4, H, W) are ambiguous and raise ValueError; pass channels. A 3-d array whose last dimension is 3 or 4 is read as one colour image.

    Parameters:

    Name Type Description Default
    x ArrayLike

    A torch tensor, numpy array, or anything numpy.asarray accepts. Tensors are detached and moved to the CPU for you.

    		 required
    rows int | None

    Number of grid rows. The number of columns is inferred.

    		 None
    cols int | None

    Number of grid columns. The number of rows is inferred.

    		 None
    griddim tuple[int, int] | None

    (rows, cols), fixing both. Missing cells are left blank and extra images are dropped. Do not combine with rows or cols.

    		 None
    vmin float | None

    Value at the dark end of the range. Defaults to the minimum of the batch.

    		 None
    vmax float | None

    Value at the bright end of the range. Defaults to the maximum of the batch. Fixing vmin and vmax stops the brightness changing from frame to frame. They apply to colour images too. uint8 input is shown as it is unless one of them is given.

    		 None
    scale_each bool

    Scale each image to its own range instead of the batch's.

    		 False
    channels str | None

    How to read a 3-d input: "first" for (C, H, W), "last" for (H, W, C), "none" for a batch of grayscale (B, H, W).

    		 None
    cmap str

    Matplotlib colormap for grayscale images.

    		 'gray'
    padding int

    Pixels of pad_value around every image in a grid. 0 puts them edge to edge.

    		 0
    pad_value int

    The value (0 to 255) of padding pixels and blank cells.

    		 0
    max_images int | None

    Show only this many images from the batch, with a warning. None shows all of them.

    		 64
    max_cols int | None

    Widest grid to choose when neither rows, cols nor griddim is given. The default grid is near-square: 3 images give 2x2, 8 give 3x3, 64 give 8x8.

    		 8

    Returns:

    Type Description
    Panel

    This panel.

    Raises:

    Type Description
    AssertionError

    If the panel already holds curves.
    ValueError

    If the shape is ambiguous or not 2-, 3- or 4-dimensional.

    Axis¶

    _Axis in the source; never created directly.

    _Axis ¶

    _Axis(plot, index: int, right: bool)

    One y-axis of a panel: the left one, or the right-hand one.

    You do not create these. plot["acc"] returns the axis that holds the metric acc, whichever side it is on. panel.left, panel.right and panel.twinx() return a panel's axes directly.

    The y setters (set_ylabel, set_ylim, set_yscale, axhline) act on this axis only. The other setters (set_title, set_xlabel, set_xlim, set_smooth, axvline, legend) act on the panel the axis belongs to, because a panel's two y-axes share one title, x-axis and legend.

    Setters can be called before the loop or during it. The figure is laid out again on the next frame.

    Example 
    plot = LivePlot(loader, "loss | acc")
plot["acc"].set_ylim(0, 1)            # the right-hand axis
plot["loss"].set_yscale("log")        # the left-hand axis
plot["loss"].axhline(0.1, "target")
